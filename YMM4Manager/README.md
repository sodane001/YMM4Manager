# YMM4 マネージャー

ゆっくりMovieMaker4(YMM4)を外から管理する Windows ソフトです(プラグインではありません)。

## できること
- YMM4の場所を選ぶ(自動で探すこともできます)/ YMM4を起動
- 素材データベース: 取り込み・フォルダー・タグ・評価・メモ・色で検索・ゴミ箱・YMM4のタイムラインへドラッグ
  (YMM4の中の YmmExplorer プラグインの素材データベースと同じ中身を使います)
- プロジェクト: 登録したフォルダーの .ymmp を新しい順に一覧、YMM4で開く、コピーを保存
  新しいプロジェクトを作る(設定のフォルダー \ プロジェクト名 \ プロジェクト名.ymmp)
- YMM4のアップデート・以前のバージョンに戻す(設定)
- プラグイン: 有効/無効の切り替え・削除・追加(.ymme / .zip / .dll)
- バックアップ: YMM4の設定・プラグイン・YmmExplorer の登録内容・素材を ZIP に保存/元に戻す

## インストーラーの作り方
1. .NET 10 SDK と Inno Setup 6 を入れます。
2. `build.bat` をダブルクリックします。
3. `bin\installer\YMM4Manager_Setup_(バージョン).exe` ができます。これがインストーラーです。

## アップデート
`YMM4Manager.csproj` の `<Version>` を上げて `build.bat` を実行し、できた新しいインストーラーを実行するだけで、
前と同じ場所へ上書きされます(設定・登録内容はそのまま。起動中なら閉じるよう案内されます)。

Inno Setup が無い時も、`bin\publish\YMM4Manager.exe` はそのまま使えます。

## フォルダー
- `Shared\` … YmmExplorer プラグインと共通のコード(素材データベース・プラグイン管理)。
  プラグイン側を直した時は、同じファイルをここへコピーしてください。
- 設定: `%AppData%\YMM4Manager\settings.json`
