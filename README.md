# YMM4 マネージャー

ゆっくりMovieMaker4(YMM4)を外から管理する Windows ソフトです。

- YMM4専用ストレージ(本体・素材データベース・プロジェクト・バックアップをまとめる場所)と、定期バックアップ(クラウドストレージにも入れられます)
- プロジェクト・素材データベース・プラグインの管理、プラグイン設定
- YMM4 のプリセット・テンプレート・過去のバージョン
- AI 質問

ソースは `YMM4Manager` フォルダーにあります。作り方はその中の `build.bat`(.NET 10 SDK と Inno Setup が必要)。
YmmExplorer プラグインと共通のコードが `YMM4Manager/Shared` に入っています。

## ダウンロード

[Releases](https://github.com/sodane001/YMM4Manager/releases) から `YMM4Manager_Setup_(バージョン).exe` をダウンロードして実行してください。
